reelforge

A personal video-clipping tool

reelforge is a private automation script run by one person. It takes long videos that person owns, cuts short vertical highlights from them, and uploads those highlights to that same person's own social accounts.

What it does

Overview

The tool runs on the owner's own computer. Given a video link, it downloads the video, transcribes the audio locally, selects a few short segments, renders them as vertical clips with captions, and publishes them to the owner's connected YouTube channel (and optionally Instagram account) through the official platform APIs.

It is not a public service. There are no other users, no sign-ups, and no shared infrastructure.

Privacy Policy

Privacy Policy

This application is operated by a single individual for their own personal use. It exists only to manage that individual's own content on their own accounts.

Data it accesses

When authorized, the app uses Google OAuth to obtain permission to upload videos to the account owner's own YouTube channel (the youtube.upload scope). It reads no other Google data.

Data it collects, stores, or shares

  • The app does not collect personal information from any third party.
  • The app does not sell, rent, or share any data with anyone.
  • The app does not use data for advertising or profiling.
  • OAuth tokens are stored only on the owner's own computer and are used solely to publish the owner's own videos. They can be revoked at any time from the Google Account permissions page.
  • Downloaded source videos and rendered clips are kept temporarily on the owner's computer and deleted after processing.

Google API Services Limited Use

reelforge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention & deletion

Because no third-party data is collected, there is nothing to request deletion of. The account owner can revoke the app's access at any time, which invalidates all stored tokens.
